# Артефакты подготовки документации для SW JProjects

Дата: 2026-07-11.

## Готовые файлы

- `publication-docs-ru.md` — русская публикационная версия.
- `publication-docs-en.md` — английская публикационная версия.
- `publication-docs-ru.html` — HTML-фрагмент для русской вкладки SW JProjects.
- `publication-docs-en.html` — HTML-фрагмент для английской вкладки SW JProjects.
- `official-structure-comparison.md` — сверка структуры с официальной спецификацией Почты России.
- `publication-payload.json` — краткое описание полей и файлов для последующей ручной публикации.

## Статус

Файлы подготовлены локально. На `web-tolk.ru` ничего не опубликовано и карточка проекта не изменялась.
