# Axioms

1. Flow остаётся platform-agnostic и language-agnostic.
2. Skills обмениваются только оформленными артефактами.
3. Stage cannot advance without required artifacts.
4. MCP registry and tool policy are operational constraints, not advice.
5. Code reading is MCP-first.
6. Symbol analysis is Serena-first.
7. Browser work is DevTools-first.
8. Shell is fallback-only and produces telemetry.
9. Assurance must evaluate behaviour, risk and verification evidence.
10. Release requires delivery artifacts, not just code changes.
11. Patch and evolve are mandatory when устойчивое знание появилось во время работы.
12. All temporary files, scratch scripts, runtime dumps, browser profiles, and disposable logs must be created only under `.webtolk/tmp/`; root-level temporary directories such as `.tmp/`, `tmp-verify/`, and ad-hoc `logs/` are forbidden.
