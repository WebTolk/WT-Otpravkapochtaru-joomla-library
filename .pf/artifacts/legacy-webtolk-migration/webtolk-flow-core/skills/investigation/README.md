# investigation

Режим отдельного исследования системы, причины проблемы и поверхности воздействия без смешивания с implementation.

## Responsibilities

- исследовать текущее поведение и контекст
- зафиксировать hypotheses, evidence и unknowns
- построить impact analysis
- определить, нужна ли дальнейшая implementation или достаточно findings
- подготовить investigation handoff
