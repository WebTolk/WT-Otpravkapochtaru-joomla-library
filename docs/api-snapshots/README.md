# JSON-снимки ответов API

Папка `latest/` содержит обезличенные JSON-снимки ответов и ошибок, полученные на локальном Joomla-стенде. После перехода к тонкому фасаду эти снимки нужно читать как примеры формы данных API Почты России и SDK LapayGroup, а не как перечень методов класса `Otpravkapochtaru`.

## Как Пересобрать

```powershell
php .\tools\capture-api-snapshots.php --joomla-root=<joomla-root> --output-dir=.\docs\api-snapshots\latest
```

Для выборочной проверки одного метода:

```powershell
php .\tools\capture-api-snapshots.php --method=shippingPoints --joomla-root=<joomla-root>
```

Скрипт версии 2 записывает в каждый снимок два поля: `target` и `method`. Поле `target` показывает владельца метода: `facade`, `otpravka`, `calculation` или `tracking`; поле `method` содержит имя метода этого владельца.

## Формат Файла

- `schema_version` - версия формата снимка.
- `captured_at` - UTC-время сбора.
- `target` - объект, через который выполнен вызов.
- `method` - имя вызванного метода.
- `group` - тематическая группа.
- `side_effects` - тип операции.
- `input` - входные аргументы после обезличивания.
- `status` - `success` или `error`.
- `duration_ms` - длительность вызова.
- `result` - тело ответа при успехе.
- `error` - класс, код и сообщение исключения при ошибке.

## Безопасность

Скрипт скрывает токены, заголовки авторизации, пароли, логины, e-mail, телефоны, ИНН/КПП, HID, имена получателей и отправителей, а также реквизиты договора. Операции с возможными побочными эффектами по умолчанию запускаются на безопасных ошибочных входных данных, чтобы получить реальные ответы API без создания, изменения или удаления настоящих отправлений.

## Текущая Папка `latest`

Часть файлов в `latest/` могла быть собрана старым скриптом, который вызывал расширенный фасад напрямую. Такие файлы остаются полезными как примеры обезличенных ответов, но актуальный контракт библиотеки описан в [публичном контракте фасада](../public-api.md), а новые снимки должны пересобираться текущим `tools/capture-api-snapshots.php`.
