# JSON-снимки ответов API

Папка `latest/` содержит реальные обезличенные JSON-снимки ответов и ошибок, полученные через установленный Joomla-пакет на локальном стенде.

## Как пересобрать

```powershell
php .\tools\capture-api-snapshots.php --joomla-root=<joomla-root> --output-dir=.\docs\api-snapshots\latest
```

Для выборочной проверки одного метода:

```powershell
php .\tools\capture-api-snapshots.php --method=getShippingPoints --joomla-root=<joomla-root>
```

При выборочном запуске скрипт пишет отдельный `<method>.index.json`, поэтому общий `latest/index.json`, собранный полным прогоном, остается неизменным.

## Формат файла

Каждый файл метода содержит:

- `schema_version` - версия формата снимка.
- `captured_at` - UTC-время сбора.
- `method` - имя метода фасада.
- `group` - тематическая группа.
- `side_effects` - тип операции: `read`, `write`, `delete` или `document-generation`.
- `input` - входные аргументы после обезличивания.
- `status` - `success` или `error`.
- `duration_ms` - длительность вызова.
- `result` - тело ответа при успехе.
- `error` - класс, код и сообщение исключения при ошибке.

## Безопасность

Снимки реальные, но перед записью обезличиваются. Скрипт скрывает токены, заголовки авторизации, пароли, логины, e-mail, телефоны, ИНН/КПП, HID, имена получателей/отправителей и реквизиты договора.

Методы с побочными эффектами по умолчанию запускаются в режиме безопасных ошибочных входных данных (`safe-error-inputs`): скрипт использует несуществующие ID, штрихкоды и тестовые данные запроса, чтобы получить реальные ответы API и примеры ошибок без создания, изменения или удаления реальных отправлений.

## Состав

Текущий `latest/index.json` содержит 34 публичных метода фасада и ссылается на 34 JSON-файла методов. Вместе с индексом в папке 35 файлов.
