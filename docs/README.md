# WT Otpravkapochtaru: документация

Документация относится к пакету `WT Otpravkapochtaru` версии `3.0.0`.

Пакет устанавливает в Joomla:

- библиотеку `WT Otpravkapochtaru library`;
- системный плагин `System - WT Otpravkapochtaru`, где хранятся учетные данные Почты России.

## Разделы

- [Документация разработчика](developer-api.md) - подключение библиотеки, учетные данные, публичные методы фасада `Webtolk\Otpravkapochtaru\Otpravkapochtaru`, entity-классы, низкоуровневые классы и исключения.
- [Практический справочник методов фасада](facade-method-reference.md) - для каждого публичного метода фасада: что делает, зачем нужен, пример кода и типовая структура данных.
- [Пользовательская документация Joomla](joomla-user-guide.md) - установка пакета, настройка системного плагина, проверка подключения, учетные данные и типовые проблемы.
