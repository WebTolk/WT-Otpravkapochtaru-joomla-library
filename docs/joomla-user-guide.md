# Пользовательская документация Joomla

## Для чего нужен пакет

`WT Otpravkapochtaru` добавляет в Joomla библиотеку интеграции с Почтой России и системный плагин с настройками доступа.

После установки другие расширения Joomla могут использовать библиотеку для:

- проверки аккаунта Почты России;
- создания и редактирования отправлений;
- расчета тарифов;
- работы с партиями и печатными формами;
- поиска отделений;
- получения трекинга по РПО.

Сам пакет не добавляет отдельный компонент в меню администратора. Основная пользовательская точка настройки - системный плагин.

## Установка

1. Откройте админку Joomla.
2. Перейдите в `Система` -> `Установка` -> `Расширения`.
3. Загрузите ZIP-пакет `WT Otpravkapochtaru_3.0.0.zip`.
4. После установки откройте `Система` -> `Плагины`.
5. Найдите плагин `System - WT Otpravkapochtaru`.
6. Откройте плагин, заполните настройки и включите его.
7. Сохраните плагин.

Пакет устанавливает две части:

- библиотеку `WT Otpravkapochtaru library`;
- плагин `System - WT Otpravkapochtaru`.

Обе части нужны: библиотека содержит код интеграции, плагин хранит настройки доступа.

## Настройки плагина

Откройте `System - WT Otpravkapochtaru`.

### Информационный блок WebTolk

В верхней части формы отображается информационный блок плагина с версией и описанием. Он нужен для быстрой проверки, что открыт правильный плагин.

### WebTolk аккаунт

Поле `WebTolk аккаунт` проверяет подключение к API и показывает данные аккаунта, если учетные данные заполнены верно.

При успешном подключении блок может показывать:

- название организации;
- ИНН;
- КПП;
- e-mail;
- номер договора;
- ESPP-код;
- статус подключения API;
- лимит API, использовано и остаток запросов.

Если настройки не заполнены или API вернул ошибку, блок покажет предупреждение или ошибку.

### `access_token`

Токен доступа к API Otpravka Почты России.

Это обязательное поле для REST-методов библиотеки: аккаунт, отправления, партии, тарифы, отделения и документы.

### `auth_mode`

Режим авторизации пользователя для заголовка `X-User-Authorization`.

Доступные варианты:

- `Пользовательский ключ` - используется поле `user_key`;
- `Логин и пароль` - используются поля `user_login` и `user_password`.

Обычно проще использовать режим `Пользовательский ключ`, если ключ выдан в личном кабинете Почты России.

### `user_key`

Пользовательский ключ для `X-User-Authorization`.

Заполняется, если выбран режим `Пользовательский ключ`.

### `user_login` и `user_password`

Логин и пароль пользователя API.

Заполняются, если выбран режим `Логин и пароль`. Библиотека сформирует авторизационное значение из пары `login:password`.

### `tracking_login` и `tracking_password`

Отдельные учетные данные SOAP-трекинга.

Они нужны только для методов трекинга:

- история операций по РПО;
- события наложенного платежа;
- пакетный трекинг через tickets.

Если эти поля пустые, REST-часть библиотеки может работать, но трекинг будет возвращать ошибку авторизации SOAP.

### `http_timeout`

Таймаут HTTP-запросов в секундах.

Значение по умолчанию - `60`. Уменьшайте его только если внешнее расширение должно быстро завершать попытку API-запроса. Увеличивайте при медленной сети или нестабильном ответе API.

## Проверка настройки

После заполнения настроек нажмите `Сохранить`.

Признаки корректной настройки:

- плагин включен;
- поле `WebTolk аккаунт` показывает данные организации;
- статус API отображается как подключенный;
- при наличии доступа к лимитам отображаются лимит, использовано и остаток.

Если блок показывает, что API не подключен, проверьте:

- заполнен ли `access_token`;
- выбран ли правильный `auth_mode`;
- заполнен ли `user_key` либо пара `user_login` / `user_password`;
- включен ли сам плагин;
- нет ли ограничений доступа к API в аккаунте Почты России.

## Использование с другими расширениями Joomla

Пакет является библиотекой. Обычно пользователь не вызывает его напрямую. Его используют другие расширения сайта: компоненты интернет-магазина, плагины доставки, интеграции заказов.

Разработчик такого расширения создает клиент:

```php
use Webtolk\Otpravkapochtaru\Otpravkapochtaru;

$client = new Otpravkapochtaru();
```

При таком использовании библиотека сама берет настройки из включенного системного плагина.

## Типовые ошибки

### Плагин выключен

Симптом: расширение, использующее библиотеку, сообщает, что конфигурация недоступна.

Что сделать:

1. Откройте `Система` -> `Плагины`.
2. Найдите `System - WT Otpravkapochtaru`.
3. Включите плагин.
4. Сохраните настройки.

### Не заполнен `access_token`

Симптом: ошибка конфигурации или невозможность выполнить REST-запросы.

Что сделать:

1. Откройте настройки плагина.
2. Заполните `access_token`.
3. Сохраните плагин.

### Неверный режим авторизации

Симптом: API отвечает ошибкой авторизации.

Что сделать:

1. Если у вас есть пользовательский ключ, выберите режим `Пользовательский ключ` и заполните `user_key`.
2. Если используете логин и пароль, выберите режим `Логин и пароль` и заполните `user_login` / `user_password`.
3. Сохраните плагин и проверьте блок аккаунта.

### Трекинг не работает, но остальная API-часть работает

Симптом: создание/поиск отправлений работает, но история операций по РПО возвращает ошибку авторизации.

Причина: трекинг использует отдельные SOAP-учетные данные.

Что сделать:

1. Проверьте `tracking_login`.
2. Проверьте `tracking_password`.
3. Убедитесь, что эти учетные данные активны для SOAP-трекинга Почты России.

### Блок аккаунта показывает ошибку API

Возможные причины:

- неверные учетные данные;
- аккаунту не разрешен доступ к API;
- API Почты России временно недоступен;
- сервер сайта не может подключиться к внешнему API;
- слишком маленький `http_timeout`.

Что сделать:

1. Проверьте учетные данные в личном кабинете Почты России.
2. Увеличьте `http_timeout`.
3. Проверьте исходящие HTTPS-подключения с сервера сайта.
4. Повторно сохраните плагин.

## Удаление

Удаляйте пакет через стандартный менеджер расширений Joomla.

При удалении пакета Joomla должна удалить и библиотеку, и системный плагин. Если другие расширения сайта используют эту библиотеку, сначала отключите или перенастройте их, иначе они потеряют зависимость.
